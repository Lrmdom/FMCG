# Product Guidelines

## 1. Core Principles
- **Efficiency First:** The FMCG service must minimize user friction. Every action, from image capture to checkout, should be as fast and intuitive as possible.
- **Privacy by Design:** User data (images, pantry contents) must be handled with strict adherence to RGPD principles. Processing should be ephemeral and minimized.
- **Smart Integration:** Seamlessly integrate with the existing Storefront without compromising its performance or UX.

## 2. Prose & Tone
- **Professional & Precise:** The tone should be technical, efficient, and direct, suitable for a productivity-oriented tool.
- **Clarity over Fluff:** Avoid verbose language. Focus on actionable information for the user.

## 3. UX Principles
- **Predictive & Proactive:** The system should anticipate user needs, specifically for restock suggestions.
- **Visible Feedback:** Every interaction, especially IA processes, must provide clear visual feedback to the user.
- **User Control:** The user must always remain in control (e.g., opt-in toggles, manual overrides for automatic cart mutations).
